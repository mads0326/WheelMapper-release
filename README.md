# Wheel Mapper for CTRacer

레이싱 휠 보조 도구. 휠 버튼에 키보드 키를 붙이고, 벤더 툴만으로 부족한
포스 피드백을 조금 더 얹습니다.

**[최신 버전 내려받기](../../releases/latest)**

---

## 이 프로그램의 위치

**휠 설정의 중심은 언제나 제조사 공식 툴입니다.**
Thrustmaster Control Panel, Logitech G HUB, MOZA Pit House 같은 벤더 툴이
회전각·전체 포스 강도·페달 보정 같은 근본 설정을 담당합니다.
먼저 그쪽에서 원하는 느낌을 만드세요.

이 프로그램은 **그것만으로 부족할 때 얹어 쓰는 보조 도구**입니다.
벤더 툴을 대체하지 않습니다.

> **힘은 더해집니다.** 센터 정렬·휠 무게 슬라이더는 벤더 툴 설정을 대신하는 값이
> 아니라 **그 위에 더해지는 값**입니다. 이미 원하는 무게가 나온다면 0 으로 두세요.

> **과도하게 올리지 마세요.** 발열, 과열 보호로 인한 힘 약화, 기어·모터·벨트
> 수명 단축으로 이어질 수 있습니다. 낮은 값에서 시작해 조금씩 올리고, 휠이
> 뜨거워지거나 힘이 갑자기 약해지면 즉시 낮추세요.

## 설치

1. 릴리즈에서 `WheelMapper-x.y.z-setup.exe` 를 받아 실행합니다.
2. 설치 중 **HidHide** 와 **vJoy** 드라이버 설치 여부를 묻습니다.
   휠 버튼의 원래 입력을 게임에서 차단하려면 두 가지가 필요합니다.
3. 드라이버를 설치했다면 **재부팅**합니다.

**vJoy 가 이미 깔려 있다면** 제어판에서 완전히 제거하고 재부팅한 뒤 설치하세요.
버전이 다르면 축·버튼 구성이 달라 조향과 페달이 엉뚱하게 들어갑니다.

**다른 매핑 프로그램과 함께 쓰지 마세요.** 키 매핑·컨트롤러 변환 계열이 같이
돌면 서로 같은 장치를 잡아 충돌합니다.

자세한 사용법은 릴리즈에 함께 올린 **사용 설명서(HTML)** 를 참고하세요.
파일 하나에 그림까지 들어 있어 브라우저로 열기만 하면 됩니다.

## Windows 보안 경고에 대하여

이 프로그램에는 **코드 서명 인증서가 없습니다.** 개인 개발 도구라 인증서를
구매하지 않았습니다. 그래서 다음이 나타날 수 있습니다.

- 실행할 때 **Microsoft Defender SmartScreen** 경고
  → `추가 정보` → `실행`
- 일부 백신의 **오탐(false positive)**
- 구글 드라이브 등에서 **공유 차단**

서명이 없는 실행 파일에 관리자 권한 요청과 드라이버 설치본이 함께 들어 있어
자동 검사에서 걸리는 것입니다. 오탐을 줄이기 위해 아래는 이미 적용돼 있습니다.

- 버전 정보 리소스 포함 (비어 있으면 휴리스틱 점수가 크게 오릅니다)
- UPX 등 실행 파일 압축 미사용
- 단일 파일 자가 압축 해제 방식 미사용

**믿을 수 없다면 설치하지 마세요.** 판단은 받는 분 몫입니다.

## 관리자 권한이 필요한 이유

게임이 관리자 권한으로 실행되면 Windows 의 UIPI 가 낮은 권한 프로그램의 키
입력을 차단합니다. 매핑한 키가 게임에 들어가려면 이 프로그램도 같은 권한이
필요합니다. 그래서 실행할 때마다 UAC 창이 뜹니다.

## 시스템 요구 사항

- Windows 10 / 11 64비트
- DirectInput 을 지원하는 레이싱 휠
- 버튼 차단 기능을 쓰려면 HidHide + vJoy (설치본에 포함)

## 문제가 생기면

고급 설정의 **로그 폴더 열기** 와 **진단 정보 복사** 로 자료를 모아 이슈로
남겨 주세요. 로그 위치는 `%APPDATA%\WheelMapper\logs\` 입니다.
